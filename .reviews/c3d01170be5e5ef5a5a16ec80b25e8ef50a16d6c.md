## Findings and dispositions

1. **Public REST increased the abuse surface.** The landing page made the already-public REST audit discoverable while only MCP was protected. The implementation now bounds every JSON request body at 500 KB, returns client errors for malformed/non-object payloads, and protects feedback writes with the configured product secret. The deterministic audit endpoints remain intentionally open because they are the no-login activation path; nginx/host rate limiting remains the appropriate layer if abuse is observed.
2. **Feedback and measurement could collapse into the public product boundary.** Feedback writes are now protected. Feedback and telemetry reads remain aggregate-only and contain no request payloads, user identifiers, or credentials.
3. **User-agent classification could still be mistaken for identity.** The report and watcher never emit a `human` or `buyer` class. Known automation is excluded conservatively; every other event is `unattributed` and requires evidence review. The report says explicitly that it contains no payment evidence.
4. **Classifier drift between watcher and weekly report.** Both paths now source the same regex and classification helper. The batch helper is regression-tested against crawler, internal, malformed, and unattributed cases.
5. **Historical telemetry contamination.** The deployed Launchpad Lint service previously wrote development/test events into the repository-local artifact. The service now labels production events explicitly and writes to a fresh runtime-owned path; the old file remains preserved as test history rather than being rewritten.

## Residual uncertainty

- A user agent can spoof or omit identity, so `unattributed` remains deliberately non-promotable without behavioral/provenance review.
- The application itself does not enforce quotas on the open REST routes. This is accepted for the present low-volume deterministic service; resource limits should be enforced at nginx if traffic changes.
- The fallback reviewer was not an opposing model. The authentication failure is recorded rather than represented as completed Claude review.
