# Retrospective adversarial review — runtime precheck ACL

Reviewed 2026-09-05 after the deployment gate exposed missing July review evidence. Claude `/review` was unavailable because the host OAuth session had expired.

- **Dangerous assumption:** granting execute/read ACL on the precheck file is sufficient when ancestor traversal permissions change.
- **Missing failure mode:** a future checkout or permission reset can remove the ACL and make restart fail closed.
- **Boundary pressure:** deployment preparation remains a host operation and must not be implied by a source checkout.

Disposition: accepted. The current runtime precheck executes successfully under the live service contract; a failed ACL will prevent restart rather than silently using an unverified runtime.
