# Retrospective adversarial review — Preflight service containment

Reviewed 2026-09-05 after the deployment gate exposed missing July review evidence. Claude `/review` was unavailable because the host OAuth session had expired.

- **Dangerous assumption:** strict systemd containment and ACL preparation could block runtime or journal access in ways health checks miss.
- **Missing failure mode:** the watcher needs boot-id access through procfs; the final live unit intentionally omits `ProcSubset=pid`, while the gateway intentionally omits `MemoryDenyWriteExecute` for V8 JIT memory.
- **Boundary pressure:** host security policy must remain deploy configuration, not leak into application semantics.

Disposition: accepted. Both contained services are active, Preflight health is green, and the watcher is consuming current journal events.
