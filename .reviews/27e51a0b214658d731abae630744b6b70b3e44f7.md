# Retrospective adversarial review — pinned Preflight Node runtime

Reviewed 2026-09-05 after the deployment gate exposed missing July review evidence. Claude `/review` was unavailable because the host OAuth session had expired.

- **Dangerous assumption:** a repository-pinned binary path and checksum could strand the service when the runtime is moved or patched.
- **Missing failure mode:** checksum verification proves binary identity, not compatibility of a new build. The release procedure therefore requires canary execution before restart.
- **Boundary pressure:** runtime supply-chain pinning can be mistaken for application correctness.

Disposition: accepted. `verify_node_runtime.sh` passes against the installed v24.18.0 binary and the live unit has used it since July.
